Guia de estudo

Conceitos essenciais para entender a estrutura.

PK

Chave primária

Identifica cada registro de maneira única dentro de uma tabela.

PRIMARY KEY (id)
FK

Chave estrangeira

Relaciona um registro a outro registro de uma tabela relacionada.

FOREIGN KEY (id_aluno)
AI

Auto incremento

Gera automaticamente o próximo número de identificação.

AUTO_INCREMENT
NN

NOT NULL

Exige que o campo receba um valor, sem permitir NULL.

NOT NULL
UQ

UNIQUE

Impede valores repetidos na coluna ou combinação de colunas indexada.

UNIQUE KEY
DF

DEFAULT

Define o valor usado quando a inserção não informa outro valor.

DEFAULT 1
